# Synology：実アカウントでの基本試験

<!-- current-version: 1.11.0 -->
対象版は **v1.11.0** です。[取得する版の確認](current-version.md) ／ [試験コース](test-start.md)

[新規導入の1〜5](synology.md)を終え、各アカウントの通知成功と「正常」表示を確認した後に行います。
この段階では自動復帰タスクをまだ登録しません。同じアカウントの他環境は停止したままにします。

## 1. 設定変更と定期通知を確認する

 次を順番に確認します。設定するのはFile Station上のconfig/mydns.confです。

| 操作 | 成功の目印 |
| --- | --- |
| DEBUG=1へ変更して保存 | 次の周期からCHECK・SKIPなどの詳細ログが出る |
| CHECK_INTERVAL=60へ変更して保存 | 次の周期以降、CHECKログが約1分間隔になる |
| FORCE_UPDATE_INTERVAL=3600へ変更して保存 | 各アカウントの前回通知成功から1時間を過ぎた確認周期でMyDNS update: OKが出る |
| 通知成功後にプロジェクトを停止・開始 | 新しいSTARTUPが出て「正常」になる。IP不変・期限前ならSKIP。stateは削除しない |


変更前の待機時間は残るため、反映までは最大で前の確認間隔だけ待ちます。
設定保存後の時刻のログを見て、過去の成功ログと取り違えないようにします。

## 2. 通常の間隔への変更を確認する

File Stationでconfig/mydns.confを開き、CHECK_INTERVAL=300へ変更します。
再起動せず次の周期以降のCHECKが約5分間隔になることを確認します。
DEBUG=0にすると詳細ログが止まり、DEBUG=1に戻すと次の周期から再び出ることも確認します。
FORCE_UPDATE_INTERVAL=3600は今回の試験中は残します。
